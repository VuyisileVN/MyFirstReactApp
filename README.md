# Student Portal 🎓

## About the Project

The Student Portal is a beginner-friendly React application created for practice and learning. It demonstrates how React can be used to build an interactive student dashboard.

The application welcomes students, displays a list of courses, and allows users to track their completed study sessions.

## Features

- **Welcome Dashboard:** Displays a welcome message with the student's name.
- **Change Name:** Allows the displayed student name to change when the button is clicked.
- **My Courses:** Displays a list of four courses.
- **Study Sessions:** Tracks the number of completed study sessions.
- **Interactive Buttons:** Updates the page when users interact with the application.
- **React State Management:** Uses the `useState` Hook to manage changing information.

## Technologies Used

- **React** — To build the user interface.
- **JavaScript** — To add functionality and interactivity.
- **CSS** — To style the application using `App.css`.
- **Vite** — To run the development server and build the project.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Visual Studio Code or another code editor

### Installation

1. Clone the repository or download the project files.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Install the project dependencies:

   ```bash
   npm install
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal, usually `http://localhost:5173/`.
